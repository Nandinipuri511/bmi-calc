# 🧮 BMI Calculator

A simple and responsive **BMI (Body Mass Index) Calculator** built using **HTML**, **CSS**, and **JavaScript**. This beginner-level project helps users calculate their BMI based on their weight and height, and provides a health category interpretation.

## 🚀 Features

- User inputs for height (in cm) and weight (in kg)
- Calculates BMI with a single click
- Displays BMI result and corresponding health category:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Basic form validation for empty or invalid inputs
- Clean and responsive design

## 🛠️ Tech Stack

- **HTML** – Structure and form elements
- **CSS** – Styling and layout
- **JavaScript** – Logic for BMI calculation and DOM manipulation
